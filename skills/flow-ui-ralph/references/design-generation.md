# 设计生成模式(无目标素材时的 FinalTarget 创建)

当用户**未提供设计稿**而要求"先做设计再还原"时,先用 AI 生成设计参考图作为 FinalTarget,再回归 flow-ui-ralph 主流程(V-Zone 拆分 → 双向 Rough Loop)。

生成执行一律委托 **flow-image** 技能(读取 `~/.claude/skills/flow-image/SKILL.md`),调用时传 `--no-open` 避免每张图都弹窗。

## 核心原则:图片是设计真相源

生成式设计的工作顺序不可颠倒:

1. 先确定视觉方向并生成设计参考图
2. 深度分析生成的图片(按 SKILL.md 的 V-Zone 验收标准模板提取设计系统)
3. 图片作为 `target/` 素材进入还原流程

禁止跳过图片生成直接写代码、凭"好品味记忆"设计。生成的图片是主艺术指导来源,代码只是翻译层。

## Section 独立性纪律

- **一个 section 一张独立大图**:8 个 section 的落地页 = 8 张图,禁止把多 section 压缩进一张拼板(文字、间距、按钮会小到无法分析)
- **禁止裁剪旧图**:某 section 需要更近的细节视图时,用相同设计语言**重新生成一张干净的独立图**,而不是从已有大图上裁剪——裁剪会破坏间距比例、字阶关系和边距
- **不清晰就重生成**:文字不可读、按钮看不清、间距不明时,重新生成该 section 的更干净版本(更大文字、更宽间距),保持同一调色板、字体氛围、组件族不变
- 需要时为一个复杂 section 生成额外的提取导向细节图(导航处理、定价卡、页脚等)

## 多图一致性

所有 section 图必须属于同一个设计世界:

- 同一调色板与背景处理
- 同一字阶逻辑与字体氛围
- 同一 CTA 样式、圆角逻辑、图标风格
- 同一组件族与图像处理手法

第 2、3、8 张图不得漂移成另一个网站。

## 反 AI-Slop 清单

生成提示词中显式规避以下模式(除非用户明确要求):

- 卡片套卡片套卡片、巨大圆角容器包裹一切
- 无意义的 pill、伪系统标记、装饰性技术标签(如 "00 orchestration layer")
- 默认紫蓝 AI 渐变、无节制的玻璃拟态、漂浮色块
- 虚假品牌词(Acme/Nexus/Quantumly)与空洞营销词(unleash/elevate/revolutionize)
- 大标题 + 微弱小字的排版、滥用全大写
- 过密 section、间距不均的视觉疲劳墙

## Hero 极简纪律

- Hero 必须像强有力的开场镜头:单一焦点、层级明显、大量负空间
- 主标题控制在 1-3 行,长了就减词而不是加行
- 不堆砌徽章、假数据、小 logo、微标签
- 首屏在小笔电视口(约 13 寸)依然干净可读

## 视觉方向组合(生成前内部选定并贯彻)

为避免重复套路,生成前内部选定一组组合并全程一致:

- **主题范式**(选 1):纯净亮色 / 深邃暗色 / 大胆工作室纯色 / 安静高级中性
- **背景性格**(选 1):细腻技术网格 / 纯色柔光渐变 / 全幅电影感图像 / 触感纹理表面
- **字体性格**(选 1):干净 grotesk / 表现力 display / 编辑感 serif+sans / 瑞士理性层级
- **Hero 架构**(选 1):电影感居中极简 / 不对称分割 / 巨型图像主导 / 编辑错位构图
- **Section 系统**(选 1):模块化 bento 节奏 / 交替编辑区块 / 海报式堆叠叙事 / 瑞士网格纪律

## 生成后衔接主流程

1. 生成的图片保存到 `<working-dir>/docs/ui/<taskname>/target/`(`fullpage.png` 或按 section 命名的参考图)
2. 按 SKILL.md「V-Zone 验收标准模板」从生成图提取设计系统:文字内容、字阶关系、间距节奏、色彩逻辑、按钮与组件形态
3. 输出 V-Zone 清单,**V-Zone 目标图仍须用户手动 crop**(主流程硬性要求不变)
4. 回归主流程 Step 2(文档澄清)继续

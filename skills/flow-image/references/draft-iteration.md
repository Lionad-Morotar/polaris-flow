# 抽卡迭代工作流（draft iteration）

用户要「先出几张看看感觉」时的标准流程：并行出多变体 → 用户评审 → 带反馈约束进入下一轮 → 定稿后补终稿比例。与 batch 模式的区别在于：抽卡的产出是一次性草稿，价值在「给用户挑方向」，不在资产交付。

## 何时进入

触发词命中即进入：「抽卡」「出几张看看」「来几版」「给我选」「draft」。也可由用户直接指定变体数量。

## 每轮数量

默认每轮 2 张，用户指定数量时遵从。每张独立调用一次生成命令——禁止用 `--n` 参数一次出多张：不同变体通常携带不同提示词微调，且独立调用的产物路径、prompt 记录一一对应，便于回溯哪一版命中了哪些约束。

## 变体命名

落盘沿用 `~/.flow-image/<YYYY-MM-DD>/<provider-seg>/<model>/` 常规模式，`--out-prefix` 用 `draft-<比例>-<形态slug><轮次>`，如 `draft-5x7-megaA3`（5:7、巨构 A 形态、第 3 轮）。轮次递增使同一形态的多轮迭代可按文件名排序回溯。

## 多参考图角色标注

抽卡常带多张参考图，必须按索引显式声明每张角色，禁止模型自由解读：

- 风格/色彩参考（背景氛围、调色板）
- 人物外观参考（仅外观，构图位置由提示词指定）
- 构图参考（定稿改比例时选定稿充当此角色）

写法示例：「Image 1 为画面风格与色彩参考：……。Image 2 仅为人物外观参考。」

## 约束累积块

每轮评审中用户确认的约束（如「天空干净不要云」「全天只有一颗亮星」「人物不超过画面 1/12」）固化为提示词末尾的不变段落，后续每一轮原样保留，只改本轮的新增变量。与 edit 模式的不变量同理：重复声明以抵抗多轮迭代中的语义漂移。

## 评审暂停是预期行为

抽卡模式下「不要暂停」条款不适用：每轮出图后停下，附上各变体的差异评估与推荐项，等用户选定或给反馈后再进入下一轮。用户选定前的任何终稿加工（压缩、落工作区）都为时过早。

## 定稿改比例

用户选定草稿后需要其他比例的终稿时：以选定稿作为第三参考图（构图参考）重新生成目标比例，提示词声明「保持 Image 3 的构图与形态，按新画幅重新布局」。禁止从竖版裁横版——裁切必然丢失标题区或人物区。

## 已知执行局限

- 极小主体：模型对「画面高度的 1/18」这类比例语言执行不足，人物常停在 1/6~1/8。可尝试像素级锚定（「约 60px 高的远处黑点剪影」），有效性待实证。
- 长串文字漂移：URL、品牌名在多轮迭代中可能漂变，默认给关键字符串加逐字母拼写锚定（见 prompting.md 的图像文字节）。

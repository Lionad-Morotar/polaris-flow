# 理想 vs 现实对比工作流（anti-render 模式）

通过并置（juxtaposition）手法生成"理想承诺 vs 残酷现实"的讽刺性视觉叙事。本模式是**提示词构建策略层**：完成状态判定、领域适配与对比维度映射后，落回主流程的 edit / 带参考 gen 出图（provider 解析与调用差异见 `providers.md`）。仅为讽刺性娱乐，不意味着现实在实际上不堪入目。

## 默认序列

1. 接收图像 → 分析内容，识别所属领域为 `$domain`，计算图片宽高比为 `$ratio`。
2. 状态判定 → 确定当前状态（破败 / 理想 / 普通），据此选定输出模式；状态模糊、无法判断意图时主动询问用户期望方向。
3. 领域适配 → 按 `$domain` 将五维对比框架映射为领域专属表达。
4. 构建提示词 → 按输出模式与五维映射构建提示词，标注原图角色，落回主流程对应模式出图。
5. 验证与汇报 → 走主流程 Step 5/7（保存、打开、汇报）。

## 状态判定与输出模式

- **破败**：质量问题、使用痕迹、维护不良；Ideal：生成理想化渲染（宣传级完美呈现）；带参考 gen（原图 = 构图/内容参考）
- **理想**：营销图、广告图、精修照片；Reality：生成轻微破败的真实面貌；edit（原图 = 编辑目标）
- **普通 / 正常**：无明显破损、日常使用状态；Comparison：理想与现实并置的对比图；edit（原图 = 内容参考）

输出模式特征：

- **Ideal**：对应领域的宣传级完美呈现——高饱和度、完美光影、无瑕疵、精心构图。
- **Reality**：对应领域日常的真实状态（非破败）——自然光线（"死亡打光"）、真实质感、日常氛围、未经修饰。
- **Comparison**：理想化渲染与真实面貌并置，排列遵循下方对比图技术规范。

落回主流程时的图片角色标注遵循 SKILL.md Step 1 的意图判定口径。Comparison 走 edit 通道而非 gen，是因为 grsapi 的 gen 端点（gpt-image-2 的 `/v1/images/generations`）不接受图片输入，只有 edit 通道（默认 `gemini-3-pro-image-preview`、bl 的 `image edit`）能把原图作为内容参考传入。

## 领域识别

基于图像内容关键词匹配 `$domain`：

- 建筑：建筑外观、城市景观、室内空间、建筑效果图、楼盘、住宅、商业空间
- 人像：人像写真、Cosplay、自拍、证件照、活动拍摄、肖像
- 产品：电商产品、商品展示、包装设计、电子产品、服饰
- 食物：美食摄影、菜品展示、烘焙、饮品、餐厅菜单
- 旅游：风景照、景点打卡、酒店房间、度假胜地
- 游戏：游戏截图、游戏宣传、UI 界面、角色设计
- 健身：健身照、运动场景、瑜伽、健身房
- 家居：室内装修、家具展示、样板间、智能家居
- 科技：产品发布会、概念设计、VR/AR、智能汽车

## 五维对比框架

所有领域共享五个核心对比维度，是提示词构建的核心：生成理想侧时把各维度拉向"理想侧"列，生成现实侧时落向"现实侧"列。映射到 `$domain` 时替换为该领域的专属表达（如食物领域的"材质"对应油润光泽与摆盘，建筑领域对应立面材质与绿化状态）。

### 1. 光影（Lighting）

- 理想侧：精心计算的完美光照；黄金时刻或柔和补光；明暗层次丰富、无死黑 / 过曝；方向性明确、立体感强
- 现实侧：自然 / 现场实际光线；硬光、顶光或平淡漫射光；曝光妥协、阴影浓重；低对比度、缺乏层次

### 2. 材质（Material）

- 理想侧：完美无瑕的表面；色彩饱和、质感强化；无灰尘、无水痕、无瑕疵；CG 般的精确反射 / 折射
- 现实侧：真实使用痕迹；褪色、污渍、磨损；自然老化、环境痕迹；混浊、不完美的反射

### 3. 色彩（Color）

- 理想侧：高饱和度、鲜艳夺目；色温精准、统一协调；后期精修的色彩增强；广告级别的视觉吸引力
- 现实侧：低饱和度、略显平淡；色温偏移、白平衡未校正；相机原生色彩还原；日常感、朴素感

### 4. 氛围（Atmosphere）

- 理想侧：充满活力、生机勃勃；精心布置的场景元素；梦幻、理想化的背景；情绪饱满、引人入胜
- 现实侧：冷清、平凡或略显尴尬；杂乱的现场环境；真实、暴露现场的环境；纪实感、冷峻客观

### 5. 构图 / 细节（Composition）

- 理想侧：完美的透视与比例；瑕疵移除、穿帮修复；精心安排的元素布局；后期添加的特效 / 光效
- 现实侧：自然的镜头畸变；保留所有现场细节；随机、不规则的真实分布；无后期加持的原始状态

## 对比图技术规范（Comparison 模式）

### 排列规则

按原图宽高比 `$ratio` 决定：

- **原图横向**（宽 > 高）：对比图上下排列，水平分割线。
- **原图纵向**（高 > 宽）：对比图左右排列，垂直分割线。

### 分割线规范

- 位置：画面正中。
- 宽度：2–5 像素。
- 颜色：纯白或极浅灰。
- 边缘：锐利清晰，无羽化。

### 内容规则

- 对比图左或上（按排列规则）：理想化渲染。
- 对比图右或下：普通现实主义（默认），或破败状态（用户明确要求强烈对比效果时）。
- **默认不添加标题文字**，保持画面纯净，让视觉对比本身说话。

## 落回主流程的纪律

- Reality / Comparison 走 edit 时显式列不变量（如 `仅沿光影/材质/色彩/氛围四个维度向现实侧调整；保持主体、构图、布局不变`），每次迭代重复以减少漂移。
- 提示词构建遵守主流程 Step 3 的增强边界：禁止添加未暗示的角色、品牌、标语、调色板。
- 出图后端、参数、落盘一律走主流程 Step 1.5 → 4 → 5，不在本模式内另行猜测路由。

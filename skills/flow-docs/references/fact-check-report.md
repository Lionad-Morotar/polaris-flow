# 判定 rubric 与输出契约

由 flow-docs Workflow B Step 4 调起。定义三态判定（Tri-state Verdict）rubric、认知边界（Cognitive Boundary）标签与报告固定骨架。

## 三态判定

```markdown
每个 L1 论断得且仅得一个判定：

CONFIRMED — 有 T1/T2 信源链，数字/日期/主体可逐项对上，时间戳在有效期内。引用关键证据源。

PLAUSIBLE by default — 论断本身合理但独立信源不足，或证据仅来自 T3/T4，或时效数据临近截止。说明什么证据能升级为 CONFIRMED。不得因「没搜到佐证」判 REFUTED。

REFUTED — 仅在找到并 quote 实际反证时：原始数据矛盾（quote 出处）、可证明不可能（给出证明）、时间线矛盾（给出时间线）、一手来源否认（quote 一手表述）。

三态全部进报告（REFUTED 是审计的核心产出，绝不丢弃）。L2 论断不判三态，呈现竞争框架；L3 论断只标注为观点。
```

## 认知边界标签

每个论断（不论档位）附且仅附一个认知边界标签：

- 公开信息充分：公开来源可独立验证该论断
- 部分公开（需内部知识）：公开信息只能验证部分，关键细节依赖非公开信息
- 未公开（推测）：论断涉及未公开信息，当前判断属推测
- 根本不可知：原则上无法验证（如未来事件、私人意图）

Why：替代置信度百分比，诚实面对不确定性而不制造虚假精确——伪贝叶斯算术恰是本技能所批判的。

## 报告固定骨架

按档位选骨架，骨架中的节必须写全，不自行发明节：

### quick

- 执行摘要：可信度评级 A-F + 一句依据 + 速览表
- 每论断一行：论断 → 三态 → 关键来源

### standard（完整报告）

1. 一级标题
2. 执行摘要：评级 A-F 一句依据 / 3 个关键发现 / 发现速览表（严重误导 | 事实错误 | 信息过时 | 准确属实 | 无法核实）
3. 详细发现：每论断走原文引用 → 三态判定 → 证据链（来源 + T 级 + 链接）→ 操控机制（命中时）→ 建议修正
4. 证伪条件与更新协议
5. 方法论说明：搜索预算执行情况、被截断论断、付费墙/匿名源限制
6. 参考来源（脚注）

### deep

standard 全部 + 作者偏见分析（预设立场、系统性强调/忽略、语言分析）+ 四维对比矩阵（见 fact-check-manipulation.md）。

### 任何档位必须保留的节

一级标题、执行摘要、参考来源三部分任何档位必须保留；其余节按档位上述要求取舍。

## 量纲纪律

standard 以上至少覆盖提取论断的 80%；不足则放宽提取再收尾——而非只验证容易验证的论断。

真实发现不足则如实输出，禁止凑数。证据链用脚注或行内来源标注灵活呈现，关键是每个数字/日期/主体可回溯到具体来源。

## 伦理边界

核查旨在提升信息质量，不构成对作者的全面否定。区分事实修正与观点压制——L2/L3 层呈现多元框架，不判「错误」。

# 操控手法识别与机制解构

由 flow-docs Workflow B Step 3 调起（仅当 Step 2 预扫描命中疑似操控点）。定义七种操控手法（Manipulation Techniques）的识别信号、取证方法与机制解构（Mechanism Deconstruction）要求。

## 预扫描

Step 2 三角测量（Triangulation）验证过程中，顺带扫描下表「识别信号」列。命中任一则将对应论断标记为疑似操控点，进入机制解构；未命中则跳过本节。

命中后的记录格式：操控类型 + 原文触发措辞，附在论断档案上。同一论断可命中多种手法，全部列出。

预扫描只覆盖表中七种操控手法，不涵盖其他逻辑谬误（稻草人、滑坡、以偏概全等）；预扫描只触发进一步取证，不单独判定「存在操控」——是否真的构成操控，取决于还原步骤能否取回被省略的上下文。

## 七种操控手法识别表

- 断章取义：识别信号 引语 <15 字、孤立无主语/时间状语；快速检测 搜索引语完整段落；机制（一句） 语义漂移：读者用当前情境填空
- 选择性报道：识别信号 单一视角、无反面证据；快速检测 主动搜「反驳 + 主题」；机制（一句） 确认偏误：遗漏不被察觉
- 时间差操纵：识别信号 称「最新」但无日期；快速检测 信息时间戳 vs 发布时间；机制（一句） 可得性层级：旧信息更易回忆
- 虚假类比：识别信号 「正如 X，Y 也会…」；快速检测 列类比对象关键差异；机制（一句） 类别错误
- 数字游戏：识别信号 百分比无基数、绝对值无对比；快速检测 要完整数学上下文；机制（一句） 数字麻木：对数字敏感对数学关系不敏感
- 因果混淆：识别信号 「因为 A 所以 B」；快速检测 验时间线 + 排混杂 + 要机制；机制（一句） 相关非因果
- 权威误用：识别信号 跨领域引用、「consensus」无证据；快速检测 核资质、观点分布、利益冲突；机制（一句） 光环效应

术语标注（报告中首次出现时标注英文）：手法名——断章取义（Context Stripping）、选择性报道（Cherry Picking）、时间差操纵（Temporal Manipulation）、虚假类比（False Equivalence）、数字游戏（Statistical Gymnastics）、因果混淆（Causal Confusion）、权威误用（Authority Misattribution）；机制名——语义漂移（Semantic Drift）、确认偏误（Confirmation Bias）、可得性层级（Availability Cascade）、类别错误（Category Error）、数字麻木（Numeracy Blindness）、相关非因果（Correlation Is Not Causation）、光环效应（Halo Effect）。

## 机制解构要求

对命中的每种手法，报告中写三段，各一句引导，不给填空模板：

- 检测：什么信号触发的判定（对应识别信号列），引用原文触发措辞
- 还原：完整上下文 / 时间线 / 数学语境是什么，全部来自搜索证据，不推测
- 认知影响：读者会形成什么错误印象，该印象与现实的偏离

还原若无法取回被省略的上下文（搜索未达一手来源），操控判定不成立，撤去操控标记。

同一论断命中多种手法时，逐一解构，不合并。

解构结论不替代三态判定：操控识别解释「如何被呈现」，三态判定回答「论断是否成立」；CONFIRMED 的论断仍可能在呈现方式上存在操控痕迹（如断章引用真实事实），两者并行标记。

Why：指出「如何被误导」比指出「错了」更有价值——前者让读者对同类话术产生免疫力，后者只是替换了一个结论。

### 分手法还原要点

还原段按命中手法的方向写，不机械套用：

- 断章取义：引语完整段落与说话者意图，文章如何通过省略改变含义
- 选择性报道：列出同主题时间范围内重大事件，找出被忽略的反例（「沉默的证据」）
- 时间差操纵：重建事件时间线，标注文章引用哪个节点、忽略了哪个更新节点
- 虚假类比：列出类比对象关键维度，标注哪些维度差异足以使类比失效
- 数字游戏：补全基数、绝对值、对比基准、统计显著性，还原完整数学语境
- 因果混淆：验证时间顺序、排除混杂变量、要求机制解释，区分共因/倒置/相关
- 权威误用：核查引用者领域与论断领域的重叠度、其观点在领域观点分布中的位置、有无利益冲突

Why：各手法的还原方向不同——断章取义还原段落、时间差重建时间线、数字游戏补数学语境；统一模板会把取证引向错误方向。

## 四维对比矩阵（仅 deep 档使用）

deep 档对每个命中论断做四维对比，每论断生成一份矩阵；standard 与 quick 档跳过：

- 事实层 — 原文呈现：具体声明；完整事实：原始数据；差异：数字/日期/主体差异
- 语境层 — 原文呈现：呈现的背景；完整事实：原始背景；差异：省略或添加的上下文
- 时间层 — 原文呈现：暗示的时效；完整事实：实际时间戳；差异：过时/超前/永恒化
- 评价层 — 原文呈现：隐含结论；完整事实：客观评估；差异：过度推断/风险隐藏

矩阵四维覆盖信息被扭曲的主要面：事实层改数字与主体、语境层改省略与添加、时间层改时效暗示、评价层改隐含结论。

对比结果写入报告详细发现节（见 fact-check-report.md），直接作为论断机制解构段的对比素材。
